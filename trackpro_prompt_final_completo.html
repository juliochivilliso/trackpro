COMANDOS SMS COMPLETOS DEL ST-901L Contraseña default: 0000 Formato: COMANDO+PASSWORD o COMANDO+PASSWORD+PARAMS ── RELAY / MOTOR (cable amarillo) ── 9400000 Cortar motor (vehículo para en 10-20s) 9410000 Restaurar motor ── SERVIDOR Y RED ── 804+PWD IP PORT Cambiar servidor: "8040000 IP 5023" 803+PWD APN Configurar APN: "8030000 internet" 710+PWD Activar modo GPRS (tiempo real) 700+PWD Activar modo SMS (sin internet) RCONF Ver configuración actual del dispositivo ── INTERVALOS DE REPORTE ── 805+PWD T Intervalo motor ON (seg, default 20) 809+PWD T Intervalo motor OFF (seg, default 180) ── ALARMAS ── 211+PWD Activar geocerca circular 210+PWD Desactivar geocerca 005+PWD METROS Configurar radio geocerca (mín 1000m) 181+PWD+T+SEG Activar alarma vibración/choque (0-120s) 180+PWD Desactivar alarma vibración SPEED+PWD KMH Configurar límite de velocidad 003+PWD Activar alarma de movimiento (anti-robo) 004+PWD Desactivar alarma de movimiento ── AHORRO DE ENERGÍA ── SLEEP+PWD MIN Activar sleep (min después de motor OFF) SLEEP+PWD 0 Desactivar sleep ── UBICACIÓN ── 669+PWD Pedir ubicación → responde Google Maps link 665+PWD HHMM Enviar ubicación diaria a hora fija 6650000OFF Desactivar ubicación programada ── CONFIGURACIÓN ── 1+N+PWD NUMERO Agregar número de control (N=1,2,3) 1+N+PWD DELETE Eliminar número de control 777+NUEVA+ACTUAL Cambiar contraseña 896+PWD+E/W+HH Zona horaria (RD = 8960000W04) 150+PWD Alertas por llamada + SMS 151+PWD Solo SMS en alertas RESTART Reiniciar dispositivo FACTORY+PWD Reset de fábrica VERNO Ver versión de firmware ## Guardar en TimescaleDB (tabla positions) 2. Redis PUBLISH 'gps:position' JSON del paquete 3. Redis PUBLISH 'gps:raw' para motor de alertas 4. Actualizar último estado en Redis: SET vehicle:{id} ## BASE DE DATOS -- TimescaleDB hypertable para posiciones GPS CREATE TABLE positions ( id BIGSERIAL, tenant_id UUID NOT NULL, vehicle_id UUID NOT NULL, lat DOUBLE PRECISION NOT NULL, lng DOUBLE PRECISION NOT NULL, speed REAL, heading REAL, ignition BOOLEAN, battery REAL, timestamp TIMESTAMPTZ NOT NULL ); SELECT create_hypertable('positions','timestamp'); CREATE INDEX ON positions (vehicle_id, timestamp DESC); CREATE INDEX ON positions (tenant_id, timestamp DESC); ## MÓDULOS NESTJS AuthModule POST /auth/login JWT access + refresh cookie POST /auth/refresh nuevo access con cookie POST /auth/logout invalida refresh token JWT incluye: { userId, tenantId, role } VehiclesModule GET /vehicles lista del tenant GET /vehicles/:id detalle + última pos GET /vehicles/:id/positions historial TimescaleDB ?from=ISO&to=ISO POST /vehicles crear vehículo PATCH /vehicles/:id actualizar POST /vehicles/:id/relay enviar comando SMS body: { action: 'cut'|'restore'|'config', params?: object } POST /vehicles/:id/command cualquier comando SMS body: { command: string } AlertsModule GET /alerts lista paginada con filtros PATCH /alerts/:id/read marcar leída POST /alerts/settings configurar umbrales por vehículo Motor de alertas (Kafka consumer): -
